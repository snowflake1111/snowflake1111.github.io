## Publish with GitHub Pages
1. Download and unzip this folder.
2. Review the project descriptions and dates.
3. If replacing the current website, back up your existing repository first.
4. Upload the contents of this folder to the root of your GitHub Pages repository (the folder containing `index.html`), preserving the `assets/` and `projects/` directories.
5. In GitHub, open **Settings → Pages** and confirm the publishing source/branch is correct.
6. Open the published site and test the navigation and links on desktop and mobile.

## CV PDF
The `assets/files/` folder is intentionally included for your CV. Add your PDF using this exact filename if you want to link it from the homepage:
`assets/files/Rebecca_Chiang_CV.pdf`

Until you add the PDF, the homepage CV button points to a file that does not yet exist. Either add the file or change that button to `cv.html`.
